A compact 0x88 chess engine in 4 KB of Python: alpha-beta search with quiescence, transposition table, killer moves, and material + piece-square evaluation. Fixed node budget per move (no wall clock), so live and replay agree.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:18080 python3 main.py
```
